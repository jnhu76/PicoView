# PicoView

PicoView is a fast, small, focused Windows 11 local image viewer built on PocketJS.

Project authority and implementation context live in `docs/PRD/`, `docs/SPEC/`, `CONTEXT.md`, and `AGENTS.md`.

The current phase is **PocketJS Windows landing / architecture spike**. Full viewer implementation should not begin until the spike gates defined in the PRD and spec pass.
